# 卒業論文用システム開発資料：日経225スマートAI分析アプリ (All_Analysis_6)　※.envファイルのAPIキーは自身のものを使用する

## 1. アプリ概要
本システムは、個人投資家の意思決定を高度に支援するために開発された、Pythonベースの統合型株式分析Webアプリケーションである。
従来の「チャートツール」や「ニュースアプリ」が提供する情報の断片化を解決し、定量的データ（株価・指標）と定性的データ（ニュース・決算）を、生成AI（Google Gemini）を用いて統合的に分析・解釈する機能を提供する。

### 特徴
- **AI主導の多角分析**: テクニカル、ファンダメンタルズ、市況、出来高の急変など、多角的な視点からAIが投資判断を生成。
- **Grounding（根拠付け）機能**: Google Searchを活用し、最新の決算やリアルタイムな市場ニュースに基づいた、ハルシネーション（嘘）の少ない分析を実現。
- **再調査・深掘り機能**: 既存の分析結果に対して「なぜ？」と問いかけることで、AIが追加調査を行う対話型インターフェース。
- **ワンストップ・レポート**: 分析結果をPDFレポートとして出力し、投資記録として保存可能。

## 2. システム要件・仕様

### 開発環境
- **言語**: Python 3.12
- **フレームワーク**: Flask (バックエンド), HTML/CSS/JavaScript (フロントエンド)
- **データベース**: SQLite3 (株価データのキャッシュ用)
- **AIモデル**: Gemini-3-flash-preview(thinking_level=high or low) ,Gemini-2.5-flash-lite(AI会社説明と高速モード用)
- **外部API**: 
  - Google GenAI API (LLM)
  - Yahoo! Finance (yfinanceライブラリ経由)
  - Google News RSS (feedparserライブラリ経由)

### 主要機能一覧
1. **テクニカル分析機能** (`/analyze`)
   - 過去1年間の株価、移動平均線（5, 25, 75日）、乖離率を計算。
   - チャートパターンに基づき、AIがトレンド（上昇・下降・揉み合い）を判定。

2. **個別株詳細分析機能** (`/analyze_full`)
   - 企業名と銘柄コードを基に、Google検索を用いて最新の決算短信や中期経営計画を調査。
   - 業績、需給、競合比較を行い、将来性を評価。

3. **出来高急増分析機能** (`/analyze_volume`)
   - 出来高が急増した日を「前後1週間」の範囲でグループ化。
   - その期間に発生した材料（ニュース）と市場反応（投資家心理）の因果関係を分析。

4. **市況分析機能** (`/analyze_market`)
   - 指定キーワード（例: "半導体", "円安"）に関連する最新ニュースをRSSから取得。
   - 市場全体のセンチメント（強気・弱気）を要約。

5. **総合分析機能** (`/analyze_total`)
   - 上記の複数の分析結果を統合し、短期・中期・長期の具体的な投資戦略を提案。

6. **PDFレポート出力** (`/export_pdf`)
   - 生成された分析結果を、整形されたPDFファイルとしてダウンロード。

## 5. 操作・実行手順(開発者目線)

### 5.1 環境構築 (初回のみ)
1. Pythonのインストール。
2. 依存ライブラリのインストール:
   ```bash
   pip install -r requirements.txt
   ```
3. 環境変数の設定:
   `.env` ファイルを作成し、Google APIキーを設定する。
   ```text
   GOOGLE_API_KEY=your_api_key_here
   ```

### 5.2 アプリケーションの起動
1. ターミナルで以下のコマンドを実行(もしくはRun Code):
   ```bash
   python app.py
   ```
2. サーバが起動したら、ブラウザで `http://localhost:5000` にアクセス。

### 5.3 分析の実行フロー
1. **銘柄選択**: 画面左上のプルダウンから分析したい銘柄を選択。または業種の欄で銘柄を絞る、または銘柄名を直接入力。
2. **データ取得**: 銘柄を入力すると、最新の株価・指標を自動的に表示。
3. **AI分析**: 
   - 「個別株分析」「テクニカル分析」などのボタンをクリックし、実行ボタンからAIによるレポート生成を開始。
   - 必要に応じて「初心者モード」や「詳細分析モード」のオプションをチェックボックスから有効化。
4. **統合判断**: 複数の分析結果が出揃ったら、分析履歴の欄からチェックボックスで対象レポートを選択し「総合分析」を実行。
5. **保存**: 結果を「PDF出力」ボタンでレポートとして保存。

## 6. 注意点
・AIモデルにはGemini-3-flash-preview(thinking_level=high or low) と、Gemini-2.5-flash-liteを使用しているが、これらのAPIの仕様変更や古いバージョンのモデル提供が終了した場合、使用するモデルを変更する必要がある。
・本アプリは多人数で同時に使用したときのテストは行なっていないため、その場合は予期せぬエラーが発生する可能性がある。
・renderのリソースは無料プランの場合512MBが最大なため、複数の処理を同時実行するとアプリ内でエラー表示が起きる可能性がある。特にPDF生成処理は数100MBのリソースを消費するため注意。
